# Editing Plan

## Objective
Turn the raw screen recording into a premium, fast-moving YouTube strategy showcase that stays focused on the TradingView chart and on-screen report data while removing browser and private UI distractions.

## Core Editing Decisions
- Use a sanitized 16:9 crop that removes browser tabs, the URL bar, and bottom UI noise before bringing the clip into Remotion.
- Open on the sharpest selloff sequence to create immediate curiosity instead of starting with the slowest part of the chart.
- Keep the final cut near 67 seconds so the pacing feels premium and retention-friendly.
- Use modern lower-thirds, stat chips, highlight boxes, and controlled zooms instead of flashy trading-video gimmicks.
- Strip the original audio entirely because the source track is effectively silent.

## Story Flow
1. Hook with a strong move and clear overlays.
2. Explain what the viewer is seeing on the XAUUSD 15-minute chart.
3. Showcase the bullish sequence with long-side markers.
4. Showcase the bearish reversal with sell markers and target tags.
5. Show that the overlays continue through mixed conditions.
6. Land on the visible report data and summarize only what is shown.
7. Finish with the free-trial and custom Pine Script CTA over the trade list.
